7. CODE FIXES IMPLEMENTED
=========================================================


---------------------------------------------------------
FIX #1 - SQLAlchemy DetachedInstanceError (Login API)
---------------------------------------------------------

Issue:
------
During login API testing, the backend failed with:

sqlalchemy.orm.exc.DetachedInstanceError

Reason:
-------
The SQLAlchemy ORM relationship:
user.role.name

was being lazy-loaded after the DB session was already closed.

Affected File:
--------------
app/services/auth_service.py

Old Code:
---------
return session.query(User).filter(User.username == username).first()

Updated Code:
-------------
from sqlalchemy.orm import joinedload

return (
    session.query(User)
    .options(joinedload(User.role))
    .filter(User.username == username)
    .first()
)

Why Change Was Needed:
----------------------
To eagerly load the User -> Role relationship before the session closes.

Impact:
-------
✔ Login API fixed
✔ Role retrieval working
✔ JWT response generation working
✔ ORM session lifecycle stabilized


---------------------------------------------------------
FIX #2 - DetachedInstanceError in Protected APIs
---------------------------------------------------------

Issue:
------
Protected APIs such as:

GET /auth/me

failed with DetachedInstanceError.

Reason:
-------
The current_user.role relationship was lazy-loaded after session closure.

Affected File:
--------------
app/core/security.py

Affected Function:
------------------
get_user_by_token()

Old Query:
----------
session.query(User).filter(User.id == user_id).first()

Updated Query:
--------------
from sqlalchemy.orm import joinedload

user = (
    session.query(User)
    .options(joinedload(User.role))
    .filter(User.id == user_id)
    .first()
)

Why Change Was Needed:
----------------------
To eagerly load the User -> Role relationship during JWT user lookup.

Impact:
-------
✔ Protected routes fixed
✔ /auth/me working
✔ JWT user extraction stabilized
✔ ORM relationship loading fixed
