ARCHITECTURE CHANGES DONE
============================================================

1. main.py Refactoring
----------------------

Previous State:
---------------
main.py contained:
- ingestion logic
- retrieval logic
- query execution
- QueryFactory integration

Problem:
--------
Onboarding service should not contain retrieval responsibilities.

Changes Done:
-------------
Removed:
- QueryFactory dependency
- retrieval execution
- sample query logic
- query-related functions

Current Responsibility:
-----------------------
main.py now handles ONLY:
✅ source download
✅ document extraction
✅ chunking
✅ embedding generation
✅ vector indexing

Final Architecture:
-------------------

main.py
   ↓
Ingestion Pipeline Only

HOW TO RUN THE ONBOARDING API
============================================================

1. Open Project Folder
----------------------

cd onboarding_api

============================================================

2. Activate Virtual Environment
--------------------------------

Windows:

venv\Scripts\activate

============================================================

3. Install Dependencies
------------------------

pip install fastapi uvicorn sqlalchemy pyyaml python-multipart bcrypt

Optional Additional Packages:

pip install python-dotenv
pip install llama-index
pip install faiss-cpu

============================================================

4. Run FastAPI Server
----------------------

uvicorn app:app --reload

============================================================

5. Swagger URL
---------------

http://127.0.0.1:8000/docs

============================================================

6. Available APIs
------------------

GET  /
GET  /health
POST /api/v1/tenant/create
